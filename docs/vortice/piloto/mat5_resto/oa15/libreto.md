# OA 15 (borrador): Ecuaciones e inecuaciones de un paso

Fuentes oficiales (se consultan siempre ambas): (E) «Sumo Primero 5.º básico», Texto del Estudiante Tomo 2, Cap. 15 «Ecuaciones e inecuaciones»; (S) «Matemática 5.º, Casa del Saber», Santillana, Tomo II.

## 1. Qué vas a aprender
Vas a resolver problemas usando ecuaciones e inecuaciones de un paso que involucren adiciones y sustracciones.

## 2. Ecuaciones de adición

- «Recuerda que podemos usar letras para representar números y cantidades desconocidas, por ejemplo x.» [E1:4873]
- «Six representa la cantidad de manzanas en la caja, entonces la ecuación x + 5 = 40 permite encontrar el valor dex.» [E1:4874-4875]
- «En una ecuación comox + 5 = 40, puedes restar para encontrarx.» [E1:4876]
- «x + 5 = 40» [E1:4877]
- «x = 40 − 5» [E1:4879]
- «x = 35» [E1:4882]
- «Resolver la ecuación es encontrar un valor parax que haga la igualdad verdadera.» [E1:4884]
- «En este caso, 35 es la solución de la ecuación.» [E1:4886]

## 3. Ecuaciones de sustracción

- «Se abrió una caja con cuadernos y se regalaron 4. Quedaron 21 cuadernos.» [E1:4888-4890]
- «x – 4 = 21» [E1:4902]
- «x = 21 + 4» [E1:4904]
- «x = 25» [E1:4907]
- «En una ecuación comox – 4 = 21, puedes sumar para encontrarx.» [E1:4926]

## 4. Practica con las actividades del libro

- «Sandra llenó una caja con manzanas. Cerró la caja y quedaron algunas manzanas afuera. Si x representa la cantidad de manzanas en la caja, escribe una expresión algebraica.» [E1:4844-4847]
- «Se abrió una caja con cuadernos y se regalaron 4. Quedaron 21 cuadernos. ¿Cuántos cuadernos había en la caja originalmente?» [E1:4888-4890]

## 5. Para recordar

- En x + a = b, se resta: x = b − a.
- En x − a = b, se suma: x = b + a.
- La solución es el valor que hace la igualdad verdadera.
