# OA 4 (borrador): División con dividendos de tres dígitos y divisores de un dígito

Fuentes oficiales (se consultan siempre ambas): (E) «Sumo Primero 5.º básico», Texto del Estudiante Tomo 1, Cap. 5 «División»; (S) «Matemática 5.º, Casa del Saber», Santillana, Tomo I, Unidad 2, Módulo 2 «División».

## 1. Qué vas a aprender
Vas a comprender y resolver divisiones con dividendos de hasta tres dígitos y divisores de un dígito, interpretando el resto y comprobando resultados.

## 2. Términos de la división

- «En una división se pueden identificar los siguientes términos: a : b = c r» [S:3101-3104]
- «Se dice que una división en los números naturales es exacta cuando el resto es igual a cero; en caso contrario la división es inexacta.» [S:3107-3111]
- «20 : 4 = 5, tiene resto 0, es una división exacta.» [E:144]
- «23 : 4 = 5, tiene resto 3, es una división no exacta.» [E:145]

## 3. Idea clave: el algoritmo de la división

- «Algoritmo de la división: Dividendo Divisor» [E:154-155]
- «78 : 4 = 19, resto 2» [E:3377]
- «Dividendo Divisor Cociente Resto» [E:3378]
- «Para comprobar el resultado de una división, se debe verificar que: Cociente Divisor Resto Dividendo» [E:146-148]
- «5 · 4 + 3 = 23» [E:149]
- «Cociente • Divisor + Resto = Dividendo» [E:8997]
- «84 • 3 + 2 = 254» [E:8998]

## 3b. Comprobación de la división (Santillana)

- «Para comprobar que el cociente de una división es correcto, se debe cumplir que: el resto debe ser menor que el divisor.» [S:3213-3214]
- «el dividendo debe ser igual que el resultado de la multiplicación entre el divisor y el cociente más el resto.» [S:3217-3218]
- «Ejemplo: en la división 21.458 : 12 = 1.788 Se cumple 21.458 = 12 • 1.788 + 2» [S:3219-3220]

## 5. Para recordar

- El resto siempre debe ser menor que el divisor.
- Para comprobar: Cociente × Divisor + Resto = Dividendo.
- Una división es exacta si el resto es 0; es inexacta si el resto es mayor que 0.
